## Components (implement as `Pg*`)

Priority order for Phase 0–3:

1. `PgReviewBar` — sticky; never unmount in review  
2. `PgInspector` — plan/reasoning; no workflow CTAs  
3. `PgButton` — primary, secondary, ghost, danger  
4. `PgInboxItem` / `PgNeedsYouRow`  
5. `PgMorningNarrative` / `PgSuggestedStart`  
6. `PgAvatar` / `PgStatusDot`  
7. `PgPeerPresenceHeader` / `PgContextStrip`  
8. `PgCommandPalette`  

Full catalog: Design System §13.

## Layout patterns

- `layout-home`  
- `layout-inbox`  
- `layout-studio` (70/30 desktop; work-first mobile)  
- `layout-company`  

## Rules

- One primary button per viewport region  
- No card unless tappable row or suggested start  
- Section labels: max 4× `text-section` per viewport  
- Review actions on work surface — never in inspector
