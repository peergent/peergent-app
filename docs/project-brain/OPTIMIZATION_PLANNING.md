# Optimization Planning

**Capability id:** `optimization` (registry) — product name: optimization planning  
**Version:** 1.0.0

## Owns

Action proposals: CTA tests, headline rewrites, channel pause/expansion proposals, targeting/schedule adjustments — each with evidence, priority, risk, reversibility, approval requirement.

## Does not own

- Executing changes
- Budget mutation
- External campaign creation

## Dependencies

- `strategy`, `channel_planning`, `creative_generation`
- `performance_interpretation` (optional; blocks aggressive proposals when insufficient)

## Policy

Working Agreement and execution mode determine whether proposals are informational or require approval.
