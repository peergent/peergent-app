# Deliverable Planning

**Capability id:** `creative_generation` (registry) — product name: deliverable planning  
**Version:** 1.0.0

## Owns

Structured deliverable plan mapping to Marketing Workspace artifacts: id, type, channel, purpose, audience, message outline, CTA, dependencies, review requirement, measurement plan, effort class, risk, provenance.

## Does not own

- Final content generation
- Publishing or external campaign creation

## Dependencies

- `strategy`
- `channel_planning`
- `brand_understanding`

## Types

Examples: `linkedin_post`, `linkedin_carousel`, `acquisition_email`, `newsletter`, `google_ads_campaign`, `landing_page`, `blog`, `instagram_post`, `campaign_concept`.
